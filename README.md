# 🏠 Evaluating the Role of Airbnb in Zurich’s Neighbourhoods
R Bootcamp Project – 2026
Azeglio Martinelli & Ana Mas Urquijo

## 🌍 Project Goal

The goal of this project is to analyze Airbnb listings in the City of Zurich and evaluate their role within neighbourhoods and the local housing market.

We examine distribution patterns, pricing determinants, host behaviour, and guest sentiment to assess whether Airbnb complements tourism infrastructure or intensifies housing pressure.

## 📂 Folder Structure
- `Data`: Raw datasets and spatial files  
- `Models`: Saved model objects (.rds)  
- `Scripts`: Main analysis file and rendered report
